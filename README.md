# News Analyzer — анализ новостного фона компаний (.ru)

Прототип (PoC) сервиса для отдела экономической безопасности / форензики:
собирает новости домена `.ru`, привязывает их к компаниям, группирует по сюжетам
и оценивает тональность с акцентом на ранний детект негатива (иски, банкротства,
аварии, уголовные дела).

Репозиторий — ответ на тестовое задание. Структура соответствует трём его частям:

| Часть задания | Где смотреть |
|---------------|--------------|
| 1. Проектирование и архитектура (стек, расчёт мощностей, план MVP→prod) | [docs/architecture.md](docs/architecture.md) |
| 2. Кластеризация новостей по атрибутам | [app/clustering/](app/clustering/) |
| 2. Тональность и ранжирование | [app/sentiment/](app/sentiment/) |
| 3. Промпт для LLM-агента по исправлению транзакций PostgreSQL | [docs/postgres_transaction_agent_prompt.md](docs/postgres_transaction_agent_prompt.md) |

---

## Что реализовано

- **Кластеризация** ([app/clustering/](app/clustering/)): извлечение атрибутов
  (компания / регион / отрасль) словарём + правилами, затем TF-IDF + агломеративная
  кластеризация с «бустом» атрибутов. Число кластеров определяется автоматически.
- **Тональность и ранжирование** ([app/sentiment/](app/sentiment/)): лексиконно-
  правиловая оценка `[-1, 1]` с обработкой отрицаний и усилителей; ранжирование
  выборки (ранг 1 — самая негативная новость).
- **API на FastAPI** ([app/main.py](app/main.py)): `/health`, `/sentiment`,
  `/cluster`, `/analyze`.
- **Docker / docker-compose**, тесты (pytest), демо-скрипт и тестовый датасет.

Сознательно использованы **прозрачные, объяснимые** алгоритмы без обучающих данных
и GPU — это выбор для MVP. Путь развития (лемматизация, NER, RuBERT, эмбеддинги +
pgvector) описан в [docs/architecture.md](docs/architecture.md).

## Быстрый старт

### Вариант 1. Локально (Python 3.12)

```bash
python -m venv .venv
# Windows PowerShell:
.venv\Scripts\Activate.ps1
# Linux/macOS:
# source .venv/bin/activate

pip install -r requirements.txt

# демонстрация на тестовом датасете (кластеры + ранжирование)
python -m scripts.demo

# запуск API
uvicorn app.main:app --reload
# Swagger UI: http://127.0.0.1:8000/docs
```

### Вариант 2. Docker

```bash
docker compose up --build
# API: http://127.0.0.1:8000  | Swagger: http://127.0.0.1:8000/docs
```

### Тесты

```bash
pytest -q
```

## Примеры запросов к API

Сводный анализ (кластеризация + тональность):

```bash
curl -X POST http://127.0.0.1:8000/analyze \
  -H "Content-Type: application/json" \
  -d '{
    "items": [
      {"id": "1", "title": "Газпром рекордная прибыль", "text": "ПАО Газпром рост выручки от экспорта газа"},
      {"id": "2", "title": "Авария на скважине Газпрома", "text": "Уголовное дело, компании грозит штраф"},
      {"id": "3", "title": "Сбербанк повысил ставки", "text": "Сбербанк поднял ставки по ипотеке"}
    ]
  }'
```

Только тональность — `POST /sentiment`; только кластеризация — `POST /cluster`
(оба принимают тот же формат `{"items": [...]}`).

## Структура проекта

```
app/
  text.py                 # токенизация, стемминг русского текста (общий слой)
  config.py               # параметры из окружения
  models.py               # Pydantic-схемы API
  main.py                 # FastAPI-приложение
  clustering/
    dictionaries.py       # справочники: компании, регионы, отрасли
    attributes.py         # извлечение атрибутов из новости
    clusterer.py          # TF-IDF + агломеративная кластеризация
  sentiment/
    lexicon.py            # словарь тональности (+ форензик-негатив)
    analyzer.py           # оценка тональности и ранжирование
scripts/demo.py           # запуск анализа над датасетом
data/sample_news.json     # 12 тестовых новостей
tests/                    # pytest: clustering, sentiment, api
docs/
  architecture.md                        # часть 1 задания
  postgres_transaction_agent_prompt.md   # часть 3 задания
Dockerfile, docker-compose.yml, requirements.txt
```

## Настраиваемые параметры (env)

| Переменная | По умолчанию | Назначение |
|------------|--------------|------------|
| `CLUSTER_DISTANCE_THRESHOLD` | `0.6` | Порог косинусного расстояния кластеризации (меньше — строже) |
| `ATTRIBUTE_BOOST` | `3` | Вес атрибутов (компания/регион/отрасль) в векторе текста |
| `SENTIMENT_NEUTRAL_BAND` | `0.05` | Полоса вокруг 0, считающаяся нейтральной тональностью |
